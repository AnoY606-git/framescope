# Участие в разработке

Начните со [сборки](docs/BUILDING.md), [архитектуры](docs/ARCHITECTURE.md) и
[метрик](docs/METRICS.md). Собственный код принимается под GPL-3.0-only;
сохраняйте применимые copyright/SPDX и лицензии зависимостей.

## Правила изменения кода

- Чистый `FrameScope.Core` не зависит от WPF, Win32 и графического драйвера.
  UI передаёт действия ответственным сервисам; backend владеет ресурсами своего API.
- Native ABI меняется одновременно в C++ и C#, с проверкой размеров, смещений и
  чтения согласованного снимка. Нельзя молча переиспользовать номер протокола.
- Отсутствующий датчик не означает 0. Любое новое число требует источника,
  единицы, области измерения и описания ограничений.
- Никакого скрытого повышения прав, глобальной регистрации Vulkan layer,
  отключения защиты Windows или расширения поддержки на CS2.
- Исправление начинается с воспроизводимого регрессионного теста поведения.
  Для гонок управляйте границей побочного действия, а не добавляйте `sleep`.
- Производительность подтверждается замером с HUD включённым/выключенным при
  одинаковых условиях; результат синтетического Demo не равен результату игры.
- Поясняющие комментарии и пользовательская документация — на русском; API,
  команды и канонические юридические тексты сохраняют исходный язык.

## Перед pull request

```powershell
python -m unittest discover -s scripts/tests -v
python scripts/check_repository.py --include-untracked
powershell -NoProfile -File scripts/verify.ps1
```

Не запускайте несколько сборок в одном `artifacts/native` одновременно.
Для renderer-изменений выполните соответствующие сценарии из
[TESTING](docs/TESTING.md); непроверенные GPU/API укажите явно.

В PR опишите проблему, итоговое поведение, проверки и ограничения. Не добавляйте
SDK, бинарные сборки, signing material, внутренние инструкции агентам, планы или
личные логи. Уязвимости сообщаются по [SECURITY](SECURITY.md).
