# Безопасность

FrameScope preview предназначен для собственного Demo под обычной учётной
записью Windows. Поддержка CS2, обход античитов и внедрение в защищённые процессы
не входят в проект. Не отключайте Defender, SmartScreen, Secure Boot или
изоляцию ядра; не устанавливайте драйвер ради preview.

Особенно важны ошибки обработки shared memory, длины/версии native ABI,
загрузки DLL, запуска дочернего процесса и разбора настроек. Воспроизводите их
на собственном Demo, без личных процессов, чужих данных и чувствительных логов.

Для приватного репозитория сообщите владельцу через доступный приватный канал.
Если включено GitHub **Security → Report a vulnerability**, используйте его.
Пока канал не настроен, сначала согласуйте безопасную передачу с maintainer;
не публикуйте exploit или секреты в обычном issue. Не предполагается, что private
vulnerability reporting уже включён.

Укажите версию/commit, Windows build, архитектуру, GPU/драйвер, API, минимальные
шаги и последствия. Пароли, токены, ключи подписи, memory dumps посторонних
процессов и персональные пути не нужны. Полный независимый security audit не
заявляется. Дополнительные границы — в [docs/SECURITY.md](docs/SECURITY.md).
