# Документация FrameScope

Для пользователя: [начало работы](USER_GUIDE.md), [метрики](METRICS.md),
[совместимость](COMPATIBILITY.md).

Для разработчика:

1. [BUILDING](BUILDING.md) — инструменты и воспроизводимые команды.
2. [ARCHITECTURE](ARCHITECTURE.md) — слои, shared memory и владение ресурсами.
3. [TESTING](TESTING.md) — автоматические проверки и настоящие API-сценарии.
4. [RELEASING](RELEASING.md) — версия, упаковка, подпись и corresponding source.
5. [VERIFICATION](VERIFICATION.md) — выполненные прогоны и их пределы.
6. [SECURITY](SECURITY.md) — границы доверия и безопасный запуск.
7. [SIGNING](SIGNING.md) — реальный статус подписи и бесплатные варианты с условиями.

Документация описывает контракты и ограничения, а исходники — фактические
сигнатуры. Результат проверки не выводится из наличия документа или теста.
