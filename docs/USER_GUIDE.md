# Начало работы

Preview разрабатывается для собственного Demo. До использования проверьте
[статус сборки](VERIFICATION.md) и [границы совместимости](COMPATIBILITY.md).

## Установка или portable

- EXE installer устанавливает приложение только для текущего пользователя,
  без UAC. Не запускайте его от администратора ради обхода ошибки.
- Portable ZIP распакуйте в отдельную доступную для записи папку. Сохраните
  `portable.txt` рядом с `FrameScope.exe`, чтобы настройки оставались рядом.
- Не смешивайте `native/` от разных версий. Закройте Demo и редактор перед заменой
  файлов; перед обновлением сохраните отдельную копию своих профилей.
- При SmartScreen warning проверьте источник и SHA-256. Подпись издателя в preview
  не обещана; не отключайте защиту Windows.
- Debug developer-пакет всегда имеет `-debug` в имени. Распаковывайте его отдельно
  от Release, лучше в собственную portable-папку. Это не «доверенная» версия и не
  освобождение от SAC; профили installed builds могут использовать общий storage.

## Проверка HUD

1. Откройте `FrameScope.exe`, выберите профиль и обычный либо компактный layout.
2. Для preview выбирайте собственный Demo и нужный API: DX11, DX12 или Vulkan.
3. Проверяйте HUD в окне настоящего Demo. Доступность настройки в редакторе ещё
   не доказывает, что соответствующий backend/датчик успешно заработал.
4. Меняйте масштаб, положение и состав показателей небольшими шагами. FPS —
   Present-интервалы; значения N/A не являются неисправным «нулевым датчиком».
5. Закройте Demo штатно. Проверьте сохранение профиля после перезапуска редактора.

Точные доступные действия определяются текущей сборкой: до проверки не следует
предполагать наличие hotkeys, автозапуска, экспорта или поддержки чужой игры.

## Если не запускается

- Нет helper/DLL: заново распакуйте **полный** пакет, проверьте `native/` и hashes.
- Vulkan не работает: проверьте установленный графический драйвер/Vulkan runtime;
  SDK для пользователя не обязателен. Не скачивайте DLL с неофициальных сайтов.
- Нет температуры/GPU sensor: источник может отсутствовать, N/A ожидаем.
- Не сохраняются настройки portable: папка должна быть доступна для записи.
- Не запускайте CS2 и защищённые процессы как тестовый target.

Для отчёта нужны версия, Windows build, GPU/драйвер, выбранные API/режим и шаги.
Удалите личные пути и идентификаторы из логов. Уязвимости — по
[SECURITY](../SECURITY.md), обычные ошибки — через issue template репозитория.
